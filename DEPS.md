# Dependencies
- quickshell
    - qt6ct
    - qt5ct for compatibility
    - qtimageformats
    - qtmultimedia
    - qt6-5compat (qt5compat on some distros)
    - qt6svg

- Notification Daemon
    - mako

- Hyprland
    - hyprlauncher
    - pyprpaper
    - hyprlock
    - hyprshutdown
    - hyprpicker (optional)

- Wlogout
    - hyprshutdown

- Optional!
    - fish shell
    - wezterm terminal

- Kvantum
    - Please install Kvantum to set the theme for QT applications

- Icons
    - tokyo-night-icons
        - https://store.kde.org/p/2053446
        - https://github.com/ljmill/tokyo-night-icons/
        Downloand and extract this icon pack to `/usr/share/icons/`
        or '~/.local/share/icons/'
        and use qt6ct to set the icon theme to `Tokyo Night-SE`

- Dolphin
    - This Rice Was designed with the Dolphin File Manager in mind.
    - For Dolphin to respect the Themes:
        QT_QPA_PLATFORMTHEME=qt6ct

- wl-clipboard for screenshots
